# System Design Study Hub

A free, self-paced system design resource — tracks, case studies, pattern deep dives, database guides, trade-off guides, an AWS service guide, and a 93-question practice vault with original model answers.

**[Open the site →](https://priyans-hu.github.io/system-design-guide/)**

## What's inside

- **Roadmap** — weekend-paced phases from fundamentals to advanced distributed systems
- **Tracks** — system design plus security, AI/LLM, testing, Go, Python, Linux, networking, career
- **Case studies** — real-world architectures (URL shortener, ride-sharing, video streaming, and more) with interactive architecture graphs, plus India-scale systems (UPI, Flipkart's Big Billion Days, JioHotstar during cricket) built up level by level
- **Pattern deep dives** — consistent hashing, bloom filters, CRDT, saga, circuit breaker, and more
- **Database guide** — SQL, key-value, document, wide-column, time-series, search, graph, vector — internals, tradeoffs, when to use
- **AWS guide** — services by building block, decision guides, cost traps
- **Practice vault** — 93 questions across five weeks, with model answers

Progress is saved in your browser and can be backed up from the Vault page.
